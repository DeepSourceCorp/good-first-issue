## What is Good First Issue?

**Good First Issue** curates beginner-friendly tasks from popular open-source projects, so developers who've never contributed before can get started quickly — without the overwhelm.

Open-source maintainers are always looking for new contributors, but getting started can feel daunting. By surfacing easy, well-scoped issues, Good First Issue removes the barrier and helps you take that first step.

We welcome all projects — old and new, big and small. To submit yours:

**[→ Submit your repository via this form](https://docs.google.com/forms/d/e/1FAIpQLSfHSt8UHvACokWv8uwiImidTIhuSCAUXnvSGs-TULshdLl9Qw/viewform?usp=header)**

### Requirements

To maintain quality, your GitHub repository must meet all of the following:

| Requirement | Description |
|-------------|-------------|
| ✅ Good First Issues | At least 3 open issues labeled `good first issue`, `beginner`, `easy`, or `help wanted` |
| 👥 Contributors | At least 10 contributors |
| 📄 README.md | Clear setup instructions for new developers |
| 🤝 CONTRIBUTING.md | Guidelines explaining how to contribute |
| 🔄 Active Maintenance | Recent commits and ongoing activity |
| ⚖️ License | A valid open-source license |

Once reviewed and approved, your project will appear on [goodfirstissue.dev](https://goodfirstissue.dev/).
