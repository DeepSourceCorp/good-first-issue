## 🎯 What is Good First Issue?

**Good First Issue** helps new developers make their first open-source contribution by curating beginner-friendly issues from popular projects.

### Why Good First Issue?

- **Lower the barrier** – New contributors often find open-source intimidating
- **Easy starting points** – We highlight issues specifically labeled for beginners
- **Build confidence** – Fixing simple issues leads to future contributions
- **Help maintainers** – Projects get more contributors, contributors get started faster

---

## ✨ Features

- 🔍 **Curated Issues** – Hand-picked beginner-friendly tasks from quality projects
- 🏷️ **Smart Filtering** – Filter by language, label, and project
- 📊 **Project Stats** – See contributor count, activity, and issue difficulty
- 🚀 **Active Projects Only** – All projects are actively maintained
- 📱 **Responsive Design** – Works seamlessly on desktop and mobile

### Requirements

Your project must meet these criteria to maintain quality:

| Requirement | Description |
|-------------|-------------|
| **Good First Issues** | At least **3 open issues** with beginner labels (`good first issue`, `beginner`, `easy`, `help wanted`, etc.) |
| **Contributors** | Minimum **10 contributors** |
| **Documentation** | Detailed **README.md** with setup instructions |
| **Contribution Guide** | **CONTRIBUTING.md** with guidelines for new contributors |
| **Active Maintenance** | Recent commits and responsive to issues/PRs |
| **License** | Valid open-source license (MIT, Apache 2.0, GPL, etc.) |

**✅ Once approved**, your project appears on [goodfirstissue.dev](https://goodfirstissue.dev/) within 24-48 hours.

## 🚀 Getting Started (Development)

Want to contribute to Good First Issue itself? Here's how to set up locally:

### Prerequisites

- Node.js 18+ 
- Bun (recommended) or npm/yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/good-first-issue.git
cd good-first-issue

# Install dependencies
bun install
# or: npm install

# Run development server
bun run dev
# or: npm run dev
```

Visit `http://localhost:3000` to see the app running.

### Available Scripts

```bash
bun run dev        # Start development server
bun run build      # Build for production
bun run generate   # Generate static site
bun run preview    # Preview production build
bun run sync       # Sync project data
```
